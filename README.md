# Спидометр

Минималистичный GPS-спидометр (PWA). Тёмная тема, дуговая шкала, два режима —
вертикальный и горизонтальный — с плавной анимацией при повороте телефона.

## Запуск на iPhone

1. Откройте сайт по **HTTPS** (геолокация в Safari работает только по HTTPS).
2. Нажмите **«Старт»** и разрешите доступ к геопозиции.
3. Для полноэкранного режима: **Поделиться → «На экран Домой»** —
   откроется как приложение без адресной строки.
4. Поверните телефон — layout перестроится с анимацией.

## Возможности

- Скорость по GPS (`watchPosition` + запасной расчёт по координатам)
- км/ч ⇄ миль/ч (запоминается)
- Максимум, средняя в движении, дистанция, время поездки
- Автомасштаб шкалы (60 → 380)
- Индикатор точности GPS (± м)
- **Демо**-режим — проверить анимации без движения
- Wake Lock: экран не гаснет во время поездки (где поддерживается)

## Файлы

| Файл | Назначение |
|---|---|
| `index.html` | разметка |
| `styles.css` | стили, портретная/альбомная раскладка, анимация поворота |
| `app.js` | GPS, шкала, статистика, хореография поворота |
| `manifest.webmanifest`, `icon-512.png` | PWA + иконка для «экрана Домой» |

Локально: `python3 -m http.server 8000` (GPS потребует HTTPS — на телефоне
открывайте через любой статический хостинг: GitHub Pages, Vercel, Netlify…).
